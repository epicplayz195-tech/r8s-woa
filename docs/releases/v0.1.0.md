First release that boots **full Windows 11** on the Galaxy S20 FE (SM-G780F, r8s, Exynos 990) from the phone's own UFS storage. Tested on bootloader G780FXXSOFYJ1 (bit 24) with Windows 11 22H2 (22621) ARM64.

**Install guide: [docs/install.md](https://github.com/epicplayz195-tech/r8s-woa/blob/main/docs/install.md)**

### Files
| File | What |
|---|---|
| `Mu-r8s.img` | Mu-Silicium UEFI for r8s (Android boot image): flash to BOOT with `tools/device/Flash-Uefi.ps1` from TWRP |
| `Mu-r8s-odin.tar.md5` | the same, for Odin's AP slot |
| `esp-r8s.img.gz` | FAT32 ESP image: UEFI Shell + R8sDiag (saves the Windows log across restarts); used by `Partition-Phone.ps1` and `Flash-Windows.ps1` |
| `r8s-drivers-arm64.zip` | Windows drivers (test-signed): `r8sufs` (UFS storage), `r8stouch` (touch), `r8slog` (log handoff + restart through the PMU), plus `r8sdisk.exe` |
| `SHA256SUMS` | checksums of the UEFI files |

UEFI from Actions run 46115433865 (commit 99d7336), drivers from run 46141288082.

### Works
- Boots Windows 11 to the desktop from UFS, unattended setup (local account `User` / `r8s`)
- Storage read/write, touch (as an absolute mouse), restart

### Not yet
- Only 1 of 8 CPU cores; shut down restarts instead of powering off
- No USB host, Wi-Fi, Bluetooth, sound, cameras, modem, battery; no GPU (software rendering)

Experimental. Back up first (`Backup-Phone.ps1`, `Backup-Android.ps1`); `Restore-Android.ps1` puts Android back.
